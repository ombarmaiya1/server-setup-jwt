# server-setup-jwt
Basic express server 

## Usage

### Clean install (recommended)
```bash
npx server-with-jwt
```
This scaffolds the backend and leaves no extra files behind.

### With npm install
```bash
npm install server-with-jwt
```
This also scaffolds the backend, but will leave a `package.json`, `package-lock.json`, and `node_modules` in your project. Run `npm uninstall server-with-jwt` after scaffolding to clean up.

## Manual scaffolding
```bash
npx server-with-jwt [project-name]
```
